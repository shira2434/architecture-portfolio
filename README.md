# אביטל גרינבוים — תיק עבודות אדריכלות

🌐 **האתר החי:** [https://avitalgrinboim.netlify.app](https://avitalgrinboim.netlify.app)

---

## על האתר

תיק עבודות דיגיטלי מקצועי לאדריכלית אביטל גרינבוים.  
האתר בנוי ב-HTML / CSS / JavaScript טהור — ללא frameworks — ומציג את עבודותיה, הגישה המקצועית שלה, ומאפשר ללקוחות פוטנציאליים ליצור קשר.

---

## מה יש באתר

### 🎬 Hero — מסך פתיחה
- תמונת רקע מלאה עם אנימציית Ken Burns (זום איטי)
- כותרת ראשית מונפשת בשלוש שורות עם fade-in מדורג
- תת-כותרת ותווית קטנה
- שני כפתורי קריאה לפעולה
- מונים מונפשים (פרויקטים / שנות ניסיון / פרסים)
- חץ גלילה מונפש
- Parallax — התוכן נע לאט בגלילה
- פס התקדמות גלילה זהב בראש הדף

### 📜 Marquee — פס גולל
- פס טקסט אוטומטי עם שמות השירותים בעברית ואנגלית
- רץ ברציפות עם fade בקצוות

### 🖼 פרויקטים — גלריה
- גריד אסימטרי 12 עמודות (כרטיסים בגדלים שונים)
- פילטור לפי קטגוריה: הכל / מגורים / ציבורי / פנים / עירוני
- Hover effect — תמונה מתקרבת, overlay עם פרטים
- אנימציית כניסה מדורגת לכל כרטיס
- לחיצה פותחת מודל מפורט

### 🔍 מודל פרויקט
- תמונה גדולה + פרטים מלאים (תיאור, שירותים, מיקום, שנה, שטח)
- ניווט בין פרויקטים עם חצים
- סגירה עם Escape / לחיצה על רקע / כפתור X

### 🔧 שירותים
- 4 כרטיסי שירות: תכנון אדריכלי / עיצוב פנים / פיקוח עליון / תכנון עירוני
- אייקון SVG לכל שירות
- Hover effect עם תאורת רקע

### 👤 אודות
- תמונת הסטודיו עם מסגרת זהב דקורטיבית
- תג ניסיון (8+ שנים)
- שני פסקאות טקסט
- רשימת כישורים עם hover fill effect
- כפתור "בואו נדבר"
- Reveal animation מימין ושמאל בגלילה

### 💬 המלצות לקוחות
- 3 כרטיסי המלצה
- Hover effect עם קו זהב תחתון
- Auto-scroll עם dots ניווט

### 🖼 סטריפ תמונות
- 5 תמונות רוחב מלא
- Hover zoom effect

### 📧 צור קשר
- טופס עם validation אמיתי
- שדות: שם / אימייל / נושא / תיאור פרויקט
- Loading state + הודעת הצלחה
- פרטי קשר: מייל / טלפון / כתובת
- קישורי רשתות חברתיות

### 🤖 צ'אטבוט
- כפתור צף בפינה שמאלית
- תשובות אוטומטיות לשאלות נפוצות
- Typing indicator (3 נקודות מונפשות)
- כפתורי הצעות מהירות

### מה אפשר לנהל — לפי טאב

#### 📁 פרויקטים
- צפייה בכל הפרויקטים בגריד
- חיפוש לפי שם / מיקום
- פילטור לפי קטגוריה
- עריכה ומחיקה של כל פרויקט

#### ➕ פרויקט חדש
- הוספת פרויקט עם: שם, קטגוריה, מיקום, שנה, שטח, תיאור, שירותים
- העלאת תמונה מהמחשב (drag & drop) או הדבקת URL
- תצוגה מקדימה של התמונה לפני שמירה

#### 🎨 עיצוב האתר — שליטה מלאה על כל פרט
- **Hero** — 3 שורות כותרת, תת-כותרת, תווית, 2 כפתורים, תמונת רקע
- **מונים** — מספר ותווית לכל אחד מ-3 המונים
- **לוגו** — שם, כיתוב, כותרת דף (tab), פוטר, זכויות
- **אודות** — כותרת, 2 פסקאות, תג ניסיון, תמונה, כישורים
- **שירותים** — כותרת ותיאור לכל אחד מ-4 השירותים
- **המלצות** — טקסט, שם ותפקיד לכל אחת מ-3 ההמלצות
- **צור קשר** — כותרת, תת-כותרת, מייל, טלפון, כתובת, רשתות חברתיות
- **Marquee** — הטקסטים בפס הגולל
- **סטריפ תמונות** — 5 תמונות
- **צ'אטבוט** — שם, הודעת פתיחה, תשובות אוטומטיות

#### 👁 תצוגה מקדימה
- iframe של האתר החי בתוך הדשבורד
- רואים שינויים בזמן אמת

#### 💾 גיבוי ושחזור
- ייצוא כל הנתונים לקובץ JSON
- ייבוא קובץ JSON לשחזור
- סטטיסטיקות: מספר פרויקטים, תמונות, קטגוריות

#### ⚙️ הגדרות
- עדכון פרטי הסטודיו
- שינוי סיסמת הניהול
- ניקוי תמונות מועלות
- איפוס כל הפרויקטים לברירת מחדל
